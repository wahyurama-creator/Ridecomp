# RideComp 0.9.3 (beta)

**Tanggal:** 2026-11-18 · Android 8.0+ · pasang langsung dari file APK

## Cara memperbarui / How to update
Ketuk **Unduh** di kartu "Versi 0.9.3 tersedia" di Beranda, atau buka Setelan → Pembaruan aplikasi. Pasang APK baru **di atas versi lama**, jangan uninstall dulu. Ride, sepeda, dan pengaturan tetap ada.
Tap **Download** on the "Version 0.9.3 is available" card, then install the APK **over the old version**. Don't uninstall first; your data stays.

Tidak yakin file mana? Pilih **arm64-v8a**. Untuk HP lama 32-bit, pilih **armeabi-v7a**.

## Perubahan / Changes
- **Kartu pemberitahuan pembaruan didesain ulang**: kartu gelap dengan label "BARU", tautan "Unduh pembaruan", dan ✕ untuk menunda. Tampil lebih ringkas dan tidak bersaing dengan tombol MULAI RIDE. Desain ini terlihat mulai dari pembaruan berikutnya setelah 0.9.3 terpasang.

## Catatan / Notes
- Tidak ada perubahan data, jadi pembaruan dari 0.9.x aman.
