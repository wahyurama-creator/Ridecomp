# RideComp 0.9.2 (beta)

**Tanggal:** 2026-11-18 · Android 8.0+ · pasang langsung dari file APK

## Cara memperbarui / How to update
Dari 0.9.1, ketuk **Unduh** di kartu "Versi 0.9.2 tersedia" di Beranda, atau buka Setelan → Pembaruan aplikasi. Pasang APK baru **di atas versi lama**, jangan uninstall dulu. Ride, sepeda, dan pengaturan tetap ada.
From 0.9.1, tap **Download** on the "Version 0.9.2 is available" card, then install the APK **over the old version**. Don't uninstall first; your data stays.

Tidak yakin file mana? Pilih **arm64-v8a**. Untuk HP lama 32-bit, pilih **armeabi-v7a**.

## Baru / New
- **Onboarding baru**:
  - Layar sambutan baru, langkah-langkah bergaya lebih modern, dan tombol utama yang selalu terlihat.
  - **Level, profil, dan sepeda bisa dilewati.** Isi nanti di Setelan, atau lewat kartu "Lengkapi profilmu" sebelum ride.
- **Pengingat profil**: kalau profil belum diisi, layar "Siap berangkat?" menampilkan kartu kecil supaya kalori, zona, dan estimasi power akurat. Kartu ini bisa ditutup.

## Catatan / Notes
- Tidak ada perubahan data, jadi pembaruan dari 0.9.1 aman.
- Koneksi Strava masih dibatasi Strava untuk sebagian pengguna. Sementara ini, gunakan Riwayat → Kirim file FIT, lalu upload di strava.com/upload.
