# RideComp 0.9.0 — rilis awal (beta) / first release (beta)

**Tanggal:** 2026-11-17 · Android 8.0+ · instal langsung dari file APK (belum di Play Store)

## Pilih file / Which file
- `RideComp-0.9.0-arm64-v8a.apk` (14 MB) — hampir semua HP Android sejak ±2017 / most phones.
- `RideComp-0.9.0-armeabi-v7a.apk` (11 MB) — HP lama 32-bit / older 32-bit phones.

Tidak yakin? Pilih arm64; bila Android menolak ("app tidak kompatibel"), pakai armeabi-v7a.

## Cara instal / How to install
1. Unduh APK di HP. / Download the APK on the phone.
2. Buka file, izinkan "Instal app tidak dikenal" untuk browser/file manager bila diminta. / Open it and allow "Install unknown apps" when asked.
3. Ketuk Instal. Pembaruan berikutnya cukup dipasang di atasnya (data tetap). / Tap Install. Later updates install on top (data kept).

## Isi / What's in it
- Rekam ride dengan GPS (layar mati pun tetap jalan), jeda otomatis, lap, pemulihan setelah HP mematikan app.
- Sensor Bluetooth: detak jantung, speed/cadence, power meter, **smart trainer (ERG)**.
- Halaman data yang bisa diatur, profil aktivitas, **sepeda tersimpan & komponennya** (pengingat servis).
- Rute GPX dengan panduan belokan & tanjakan, **peta online** (OpenFreeMap) atau garis saja tanpa internet, **kembali ke start**.
- Rekor, segmen, beban latihan, **rencana latihan** (Base Zona 2, Persiapan lomba, Gran Fondo, buat sendiri) dengan zona target saat ride.
- **Pengumuman suara**, pengingat minum/makan, deteksi insiden + SMS darurat (opsional).
- Export FIT/GPX, kartu share, **upload Strava** (opsional), backup terenkripsi.
- Bahasa Indonesia & English, **widget layar utama**.
