# RideComp 0.10.2 (beta)

**Tanggal:** 2026-11-22 · Android 8.0+ · pasang langsung dari file APK

## Cara memperbarui / How to update
Ketuk **Unduh** di kartu pembaruan di Beranda, atau buka Setelan → Pembaruan aplikasi. Pasang APK baru **di atas versi lama**, jangan uninstall dulu. Ride, sepeda, dan pengaturan tetap ada.
Tap **Download** on the update card on Home, then install the APK **over the old version**. Don't uninstall first; your data stays.

Tidak yakin file mana? Pilih **arm64-v8a**. Untuk HP lama 32-bit, pilih **armeabi-v7a**.

## Perubahan / Changes
- **Sinyal GPS hilang di hutan atau terowongan:**
  - Saat mengikuti rute GPX, jarak yang terlewat kini dihitung **sepanjang rute**, tidak lagi garis lurus yang memotong tikungan.
  - Di peta detail ride, bagian tanpa sinyal digambar **putus-putus**.
  - Topik Bantuan baru **Sinyal GPS hilang** berisi tips menjaga sinyal.
- **Peta di layar ride bisa digeser ke samping.** Sebelumnya geseran malah memindah halaman. Untuk pindah halaman, geser di area angka di bawah peta.
