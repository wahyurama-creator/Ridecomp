# Feature Report — T9.1: Smart trainer (FTMS + ERG)

**Tanggal:** 2026-11-17
**Branch:** `feature/T9.1-smart-trainer`
**Status:** Diuji di perangkat (trainer simulasi), di-merge ke `main`

## 1. Ringkasan
Smart trainer modern (BLE **FTMS**: Wahoo KICKR, Tacx, Elite, Zwift Hub, Thinkrider, dll.) bisa dipasangkan di tab Sensor ("Smart trainer (ERG)"). Saat ride, trainer memberi power, cadence, dan kecepatan (sensor milik sepeda tetap diutamakan), dan **ERG** menahan beban di target watt: bilah di layar ride "ERG −10 · 143 W · +10"; sesi rencana dengan FTP → target awal di tengah zona (sesi interval Z4–Z5 mulai di Z2 dengan tombol **Santai** / **Zona N**); tanpa FTP 100 W. Target dilepas saat ride berakhir.
