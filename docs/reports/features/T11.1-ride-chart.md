# Feature Report — T11.1: Komponen grafik `RideChart`

**Tanggal:** 2026-11-19
**Branch:** `feature/T11.1-ride-chart`
**Status:** Diterima (pemilik menyetujui rencana; pengukuran rilis ditunda ke akhir Fase 11 atas pilihan pemilik)

## 1. Ringkasan
Grafik baru `RideChart` di `:ui-common` menggantikan `AxisLineChart` di halaman detail ride. Angka sumbu kini bulat (1-2-5 × 10ⁿ: 0 · 10 · 20 · 30 km/j, 120 · 125 · 130 m), label jarak bulat di bawah (2 · 4 · 6 km), satuan di pojok sumbu, garis bantu tipis, elevasi abu-abu samar di belakang grafik kecepatan, garis rata-rata putus-putus, serta sentuh/geser untuk membaca nilai. Setiap grafik paling banyak 300 titik (rata-rata per kelompok sampel) sehingga ride 3 jam tetap ringan; celah sensor digambar putus.

## 2. Perubahan per lapisan
| Lapisan | File/kelas | Keterangan |

- `./gradlew ktlintCheck detekt lint test koverVerify assembleDebug`: ✅ exit 0 (setelah perbaikan terakhir).
- Uji perangkat (realme RMX3830, build **debug**, ride simulasi 1 menit "Gowes Pagi" 0,50 km, uji oleh subagent): sumbu bulat di semua tab (Kecepatan 0–40, Elevasi 120–135, HR 0–200, Cadence 0–100, Power 0–300), label 0,1–0,4 km, satuan tampil, sentuh/geser berfungsi, tanpa crash/leak. Temuan (latar elevasi terlalu pekat; plot bergeser antar tab) diperbaiki dan dicek ulang dengan tangkapan layar.

Memori PSS 131 MB (Riwayat) → 193 MB (detail terbuka, termasuk peta MapLibre yang sudah ada sebelum Fase 11). Debug tanpa R8 lebih lambat; **angka resmi §8 diukur dengan build rilis di akhir Fase 11**, termasuk pembanding sebelum Fase 11 untuk batas memori < 20 MB.

## 8. Penyimpangan dari spesifikasi / RULE-EXCEPTION
- Rencana menyebut "rata-rata per ember **jarak**"; diimplementasikan per ember **sampel berurutan** (1 Hz → setara waktu). Lebih sederhana, tanpa ember kosong saat berhenti, dan sumbu X tetap jarak. Dicatat di D-115.
- Pengukuran performa dengan build rilis ditunda ke akhir fase (pemilik: "Ukur dengan debug saja").

## 9. Risiko & bug yang diketahui
- Batas memori §8 belum terbukti dengan build rilis (lihat §6).
- Ride sangat pendek (< 0,1 km) tidak menampilkan label jarak (sengaja, terlalu rapat).

## 10. Cara menguji (untuk pemilik proyek)
1. Buka Riwayat → pilih ride yang punya sensor.
2. Ganti tab Kecepatan/Elevasi/HR/Cadence/Power: angka sumbu bulat, satuan di kiri atas, plot tidak bergeser.
3. Di tab Kecepatan, elevasi tampil abu-abu samar di belakang.
4. Sentuh dan geser grafik: garis penanda + nilai pada jarak itu.
