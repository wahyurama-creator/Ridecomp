# Feature Report — T9.2: Widget layar utama

**Tanggal:** 2026-11-17
**Branch:** `feature/T9.2-home-widget`
**Status:** Diuji di perangkat, di-merge ke `main`

## 1. Ringkasan
Widget "RideComp" 4×2 untuk layar utama: sesi rencana hari ini (atau istirahat / "Siap gowes?" tanpa rencana / rencana selesai), "Minggu ini: N ride · X km", dan tombol **MULAI RIDE** yang membuka persiapan ride. Saat ride berjalan: "● Ride berjalan · jarak · waktu" dan **BUKA RIDE**.

## 2. Perubahan per lapisan
| Lapisan | File/kelas | Keterangan |
|---|---|---|
| Domain (`:core`) | `usecase/WidgetUseCases.kt` (`LoadWidgetSummaryUseCase`) | Rencana hari ini, total minggu ini (Senin), satuan |
| Platform | `RideWidget`, `ThrottledRideWidget` (`RecordingDependencies.kt`), `RecordingService` | Pembaruan ≤ 1×/menit saat ride + saat ride berakhir |
| App | `widget/RideCompWidget.kt`, `navigation/IncomingWidget.kt`, `MainActivity` (aksi + `onStop`), `RideCompApp` (navigasi), `res/layout/widget_ride.xml`, `res/xml/ridecomp_widget_info.xml`, warna/dimens/strings, manifest | RemoteViews |

## 3. Dependency baru
Tidak ada (tanpa Jetpack Glance).

## 4. Resource & siklus hidup
Tidak ada resource berat: pembaruan widget berjalan di `goAsync()` dengan batas waktu 5 dtk; tidak ada service/alarm baru (pembaruan sistem 30 menit).

## 5. Checklist kode
- [x] Ringkasan dari use case `:core`; string en/id dengan plural; warna/dimens di resource.
- [x] Layout hanya view yang diizinkan RemoteViews di Android 8+ (lint RemoteViewLayout).

## 6. Hasil testing
- `./gradlew ktlintCheck detekt lint test koverVerify assembleDebug`: ✅ BUILD SUCCESSFUL.
- Uji perangkat (subagent Sonnet, realme RMX3830, launcher realme UI): widget ditambahkan dari pemilih widget; teks "RideComp · Siap gowes? · Minggu ini: 2 ride · 1,67 km · MULAI RIDE"; kartu gelap membulat, judul & tombol oranye, tidak ada teks terpotong; ketuk MULAI RIDE → app terbuka di "Siap berangkat?" (tanpa memulai ride); Batal → tidak ada rekaman. Crash buffer kosong. Widget dibiarkan di layar utama.
- Catatan: pratinjau di pemilih widget memakai bahasa sistem HP (Inggris) — launcher membaca deskripsi dengan locale sistem, bukan bahasa per-app; setelah dipasang widget memakai bahasa app.
- Belum diuji di perangkat: tampilan saat ride berjalan (logika sama dengan pembaruan lain; dicakup kompilasi & alur service).

## 7. Keamanan
Receiver ter-export untuk `APPWIDGET_UPDATE` (RULE-EXCEPTION, D-96, threat model 11 §C diperbarui); PendingIntent eksplisit immutable; aksi widget hanya membuka layar; tanpa lokasi di widget.

## 8. Penyimpangan
RULE-EXCEPTION receiver ter-export (D-96).

## 9. Risiko & bug yang diketahui
- Ruang kosong antara teks dan tombol pada ukuran 4×2 besar (disengaja: tombol di bawah).
