# Feature Report — T11.13: Paket peta per provinsi

**Tanggal:** 2026-11-20
**Branch:** `feature/T11.13-region-packs`
**Status:** Selesai sesuai cakupan yang dipilih pemilik (skrip lengkap untuk 38 provinsi; uji & unggah 1 provinsi)

## 1. Ringkasan
Skrip `scripts/maps/build-regions` (Python 3 standar, di Mac pemilik) memotong build harian Protomaps per provinsi lewat `pmtiles extract --bbox` (HTTP Range, tanpa mengunduh planet), memverifikasi file, mencatat SHA-256 dan ukuran, mengunggah ke GitHub Release `maps-YYYY-MM` (dengan konfirmasi), lalu menulis **indeks wilayah** yang ikut APK untuk T11.12. Bbox 38 provinsi tersimpan di `scripts/maps/provinces.json`. Uji dan unggahan pertama: **DI Yogyakarta**, rilis publik `maps-2026-11`.

- Zoom 0–14, bukan 0–15 (pilihan pemilik): file ±3–4× lebih kecil dan kemungkinan tidak perlu dipecah per kabupaten. Skrip tetap menandai file > 300 MB.
- Baru 1 dari 38 provinsi dibuat dan diunggah (pilihan pemilik); 37 lainnya dijalankan pemilik dengan `extract` → `upload` → `index`.

## 9. Risiko & bug yang diketahui
- GitHub menampilkan rilis `maps-2026-11` sebagai "Latest" karena rilis aplikasi berstatus pre-release (hanya tampilan halaman Releases; aplikasi tidak terpengaruh).
- Bbox provinsi kepulauan mencakup laut luas, jadi tawaran wilayah di T11.12 bisa tumpang tindih di perbatasan; T11.12 akan memilih wilayah dengan bbox terkecil yang memuat lokasi.
- StrictMode 111 ms saat kembali dari pemilih file impor (fitur impor T3.4, bukan kode baru): masuk daftar task `fix/` StrictMode.

## 10. Cara menguji (untuk pemilik proyek)
1. `brew install pmtiles`, lalu `scripts/maps/build-regions extract --only jawa-tengah` → file di `~/RideComp-maps`.
2. `scripts/maps/build-regions upload --release maps-2026-11` → ketik `yes`.
3. `scripts/maps/build-regions index --release maps-2026-11` → commit `regions.json`.
