# Feature Report — T12.2: Pemindaian luas "Tampilkan semua perangkat Bluetooth"

**Tanggal:** 2026-11-21
**Branch:** `feature/T12.2-wide-scan`
**Status:** Selesai (diuji di HP dengan Aolon GTR 3 milik pemilik)

## 1. Ringkasan
Layar Sensor punya sakelar **Tampilkan semua perangkat Bluetooth** (default mati). Kalau dinyalakan, pindai berjalan tanpa filter layanan, tetap 15 dtk. Yang ditampilkan hanya perangkat bernama dengan sinyal ≥ −90 dBm, dan perangkat tanpa nama hanya bila sangat dekat (≥ −60 dBm). Perangkat yang belum diketahui jenisnya bertanda "Belum diperiksa" dengan tombol **Periksa**: RideComp menyambung sebentar, membaca daftar layanannya, lalu selalu memutus. Bila ada layanan HR/CSC/CP/FTMS, perangkat langsung disimpan sebagai sensor biasa. Bila tidak ada, muncul "… tidak membagikan detak jantung atau data sepeda …". Bila tidak terjangkau, muncul pesan "tidak bisa dihubungi".

Hasil dengan Aolon GTR 3: jam muncul sebagai `Aolon GTR3(ID-A05B)`, dan Periksa menunjukkan tidak ada Heart Rate Service. Ini kasus B di T12.1.

## 8. Penyimpangan dari spesifikasi / RULE-EXCEPTION
- BAT-04 ("scan selalu dengan filter UUID") dilonggarkan untuk pindai luas: opsional, default mati, tetap bertimeout. Dokumen 09 diperbarui (D-134).
- Spesifikasi menyebut "simpan sebagai sensor HR". Implementasi menyimpan semua jenis yang ditemukan (HR/CSC/CP/FTMS), supaya sensor sepeda yang tidak mengiklankan layanannya juga bisa dipakai.

## 9. Risiko & bug yang diketahui
1. Jam tangan sering tidak mengiklankan diri selama aplikasi bawaannya (mis. GloryFit) memegang koneksi. Panduan untuk ini masuk T12.3.
2. Saringan −90/−60 dBm bisa menyembunyikan sensor tanpa nama yang jauh. Pindai biasa tetap menemukan sensor standar.
3. Sakelar tidak diingat setelah layar ditutup (sengaja, default mati).

## 10. Cara menguji (untuk pemilik proyek)
1. Sensor → nyalakan **Tampilkan semua perangkat Bluetooth** → Cari sensor (Bluetooth jam aktif, aplikasi bawaan jam ditutup).
2. Jam muncul "Belum diperiksa" → **Periksa**.
3. Jam dengan berbagi HR → tersimpan sebagai sensor HR. Jam tanpa HR → pesan "tidak membagikan detak jantung".
