# Feature Report — T13.4: Layar ride & persiapan ride

**Tanggal:** 2026-11-21
**Branch:** `feature/T13.4-ride-screens`
**Status:** Selesai 2026-11-21

## 1. Ringkasan
Di layar < 360 dp: layar jeda memakai waktu bergerak 48 sp dan tombol LANJUTKAN 72 dp sehingga **SELESAI tidak terpotong** (audit P2 #3); cincin "menunggu GPS" di Persiapan ride dan cincin hitung mundur insiden lebih kecil. Layar ride dan Ringkasan sudah muat di 320 dp, tidak diubah. Di 360 dp ke atas tidak ada yang berubah.

## 6. Hasil testing
- `WindowWidthClassTest` diperluas (6 token: `Regular` = nilai lama, `Compact` lebih kecil dan dalam batas; cincin hitung mundur ≥ 160 dp agar angka 96 sp muat).
- `./gradlew ktlintCheck detekt lint test koverVerify assembleDebug`: ✅.
- Perangkat (realme RMX3830, app debug, 320 × 569 dp seperti Sony XZ lewat `wm size 720x1280` + `wm density 360`, lalu dikembalikan):
  - Ride simulasi: layar ride muat (angka utama, PAUSE/LAP); layar jeda **sebelum**: SELESAI terpotong di tepi bawah; **sesudah**: SELESAI terlihat penuh.
  - Ringkasan: "max 31,8 km/h" satu baris; keyboard tidak muncul (`mInputShown=false`).
  - Pemulihan ride setelah app dimatikan (install di tengah ride): "Ride belum tersimpan ditemukan" → Lanjutkan → layar jeda. Ride simulasi kedua dibuang; tidak ada service tersisa.
  - Cincin GPS (GPS asli, menunggu): 152 dp; masih sedikit di bawah kartu profil, layar bisa di-scroll dan "Mulai tanpa menunggu" terlihat (P3).
  - Layar insiden tidak bisa dipicu di uji ini; dijaga oleh test token.
- `compare.py` baseline (APK `main` sebelum T13.4) vs T13.4, 25 layar: **412 dp identik, 360 dp identik**, 390 dp identik kecuali `home` (baseline tertutup dialog izin notifikasi Android; Beranda tidak memakai token T13.4); 320 dp hanya `pre_ride` berubah (cincin GPS).

## 7. Keamanan

## 8. Penyimpangan dari spesifikasi / RULE-EXCEPTION
Rencana menyebut skala angka utama dan lebar LAP di `COMPACT`; tidak diperlukan karena sudah muat di 320 dp (D-145).

## 9. Risiko & bug yang diketahui
1. Layar insiden 320 dp belum dilihat di perangkat.
2. Layar jeda di 360 dp tidak bisa dibandingkan piksel (waktu total berjalan); dijaga oleh token `Regular` dan cabang `REGULAR` → `HERO`.

2. MULAI → PAUSE: SELESAI terlihat penuh.
