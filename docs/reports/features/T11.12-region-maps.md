# Feature Report — T11.12: Peta wilayah otomatis

**Tanggal:** 2026-11-20
**Branch:** `feature/T11.12-region-maps`
**Status:** Selesai (opsi dipilih pemilik; uji HP lulus)

## 1. Ringkasan
Beranda menawarkan **"Peta offline DI Yogyakarta · 21 MB · lewat Wi‑Fi"** dengan pilihan Unduh, Perbarui, Lanjutkan, atau ✕ Nanti. Wilayahnya dikenali dari titik akhir ride terakhir tanpa permintaan GPS baru. Setelan → Peta mendapat bagian **Peta per provinsi**: semua wilayah di indeks, wilayahmu paling atas, dengan tombol unduh/batal/hapus dan sakelar "Unduh juga lewat data seluler" (default mati). Unduhan memakai HTTPS dari rilis proyek dan bisa dilanjutkan. Setiap file dicek SHA-256 lalu header PMTiles sebelum dipakai peta ride dan rute. Unduhan dijeda saat aplikasi ke latar atau saat ride dimulai.

## 6. Hasil testing
- Unit test: `MapPackUseCasesTest` (validasi indeks: URL asing/hash/nama ditolak, skema baru diabaikan; wilayah = bbox terkecil; tawaran mengikuti ride terakhir, hilang saat ride, "Nanti" per versi, wilayah lain ditawarkan; unduh → terpasang, versi indeks baru → perbarui, hapus; jeda, lanjut setelah restart, batal menghapus; ride menjeda; Wi‑Fi wajib tanpa izin, checksum gagal, tanpa jaringan, saat ride), `OfflineMapsViewModelTest` (unduh, disembunyikan dari daftar impor, hapus dengan konfirmasi, data seluler), test Beranda & DI diperbarui.
- `./gradlew ktlintCheck detekt lint test koverVerify assembleDebug`: ✅ BUILD SUCCESSFUL, exit 0.
- Uji perangkat (realme RMX3830, Wi‑Fi, subagent Sonnet):
  - Beranda menampilkan "Peta offline DI Yogyakarta · 21 MB · lewat Wi‑Fi" (ride terakhir pemilik di DIY).
  - Setelan → Peta: "Wilayahmu · 21 MB · belum diunduh". Unduh → "Mengunduh 1,4 MB dari 21 MB" → Home: `.download` 1.572.326 byte dan **tidak bertambah** selama di latar → buka lagi: "dijeda, ketuk untuk lanjut" → ketuk: **lanjut dari 1,57 MB** (4,3 MB, bukan mulai ulang) → "tersimpan di HP".
  - File 21.295.529 byte, **SHA-256 cocok**, tanpa sisa `.download`; penyimpanan "21 MB"; kartu Beranda hilang setelah terpasang.
  - Hapus dengan konfirmasi → kembali "belum diunduh", folder kosong; sakelar data seluler kembali mati. **HP kembali seperti semula.**
  - Logcat: tanpa FATAL, tanpa leak, **tanpa StrictMode** (tidak ada lagi "untagged socket" saat unduh).
  - Temuan diperbaiki: teks di bawah sakelar data seluler kini benar di kedua keadaan.

## 9. Risiko & bug yang diketahui
- Tidak diuji di HP: unduhan lewat data seluler, unduhan dari tombol kartu Beranda (memanggil fungsi yang sama dengan Setelan), dan jalur "koneksi terputus" (dicakup unit test).
- Saat ini indeks hanya berisi DI Yogyakarta; provinsi lain muncul setelah pemilik menjalankan skrip T11.13 dan merilis APK dengan indeks baru.

## 10. Cara menguji (untuk pemilik proyek)
1. Setelan → Peta → Peta per provinsi → unduh DI Yogyakarta (Wi‑Fi).
2. Tekan Home di tengah unduhan, buka lagi, ketuk unduh: lanjut dari bagian terakhir.
3. Setelan → Peta online: Mati, lalu buka ride/rute di DIY: peta dari file wilayah.
