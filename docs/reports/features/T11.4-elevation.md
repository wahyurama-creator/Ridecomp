# Feature Report — T11.4: Elevasi (rombak)

**Tanggal:** 2026-11-19
**Branch:** `feature/T11.4-elevation`
**Status:** Diterima (rencana disetujui pemilik)

## 1. Ringkasan
Bagian **Elevasi** kini mengikuti susunan referensi: grafik ketinggian terhadap jarak, lalu **Kenaikan elevasi**, **Elevasi maks** (disorot), Penurunan, dan Elevasi min.

Sumbu Y memakai rentang data ditambah ±10 % ruang di atas dan bawah sebelum dibulatkan. Dengan begitu garis tidak menempel di tepi grafik (120–132 m → sumbu 115–135 m). Sumbu tidak turun di bawah 0 bila datanya tidak. Grafik dan bagian disembunyikan bila tidak ada data ketinggian (sudah sejak T11.2).
