# Feature Report — T11.14: Penyimpanan, baterai, keamanan peta offline

**Tanggal:** 2026-11-20
**Branch:** `feature/T11.14-map-storage`
**Status:** Selesai (opsi dipilih pemilik; uji HP lulus)

## 1. Ringkasan
Batas total peta offline yang bisa dipilih (500 MB / **1 GB** / 2 GB) untuk peta impor dan peta provinsi bersama. Peta yang tidak muat ditolak dengan pesan yang jelas. Setelan → Peta memberi peringatan kalau sisa ruang HP kurang dari 500 MB. Unduhan langsung gagal kalau server menyebut ukuran yang tidak sesuai indeks. File sementara usang dibersihkan otomatis. Atribusi gabungan tampil saat cache dan peta wilayah tampil bersama. Teks panduan Peta diperbarui.

Syarat yang sudah dipenuhi task sebelumnya: validasi header PMTiles (T3.4), HTTPS saja dan unduhan yang bisa dibatalkan (T11.12), atribusi peta offline OSM + Protomaps (T11.13).
