# Feature Report — T11.2b: Peta tidak tampil saat aplikasi baru dibuka

**Tanggal:** 2026-11-19
**Branch:** `fix/T11.2b-map-cold-start`
**Status:** Diterima (regresi T11.2a, ditemukan saat uji T11.3; diperbaiki sebelum lanjut)

## 1. Ringkasan
Setelah T11.2a, peta di detail ride tetap krem kosong bila detail dibuka dari aplikasi yang baru dijalankan. Thread render MapLibre (`Mbgl-EGLConfigChooser`) tidak pernah mulai dan tidak ada surface di SurfaceFlinger. Kegagalannya 3 dari 3 kali dari aplikasi dingin; pembukaan kedua berhasil.

Verifikasi T11.2a terlewat: yang diperiksa hanya tangkapan setelah scroll (peta dibuat ulang), bukan tangkapan pertama.

## 2. Penyebab (diuji satu per satu di HP)
| Hipotesis | Hasil |
|---|---|
| Urutan `MapLibre.getInstance` | Tetap gagal (0/2) |
| Library dimuat di thread IO | Dimuat di thread utama tetap gagal (0/2) |
| Opsi dibuat di thread IO | Dibuat di thread utama: 1/2 → bergantung waktu |
| Kode sebelum T11.2a | Berhasil 4/4 |

Kesimpulan: `MapView` yang ditambahkan **belakangan ke dalam `Box` yang sudah ada** (setelah persiapan ±0,3 detik) tidak memulai surface GL pada pembukaan pertama.

## 3. Perbaikan
`RouteMap` kini menampilkan `Box` kosong selama persiapan. Setelah siap, seluruh peta (`PreparedRouteMap`: `Box` + `AndroidView` + `MapView`) menggantikan placeholder dalam satu komposisi, sama seperti struktur sebelum T11.2a. Persiapan tetap di latar (D-117). `MapLibre.getInstance` dipanggil di thread utama setelah library dimuat.

## 4. Dependency / keamanan
Tidak ada dependency, izin, atau komponen baru.

## 5. Hasil testing
- **Gradle:** `./gradlew ktlintCheck detekt lint test koverVerify assembleDebug` ✅ exit 0.
- **Uji di RMX3830, build debug, dari aplikasi dingin:**
  - Peta ter-render (EGL mulai) 3/3 dan 4/4 di dua rangkaian uji. Peta tampil dan pas dengan rute.
  - StrictMode saat membuka detail dan scroll turun-naik: 0 pelanggaran di 3 kali uji (dengan perekam jejak sementara, tidak di-commit).
- **Tidak diuji ulang** karena tidak berubah: kartu Peta di galeri Bagikan (`rememberRouteSnapshot`) tetap seperti T11.2a.

## 6. Pelajaran
Uji peta harus memeriksa **tangkapan pertama dari aplikasi dingin**, bukan hanya setelah scroll.
