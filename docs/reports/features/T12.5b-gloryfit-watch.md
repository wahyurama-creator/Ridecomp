# Feature Report — T12.5b: Sensor "Jam tangan (eksperimental)" untuk Aolon GTR 3

**Tanggal:** 2026-11-21
**Branch:** `feature/T12.5b-gloryfit-watch`
**Status:** Selesai, diuji di HP dengan jam milik pemilik. Penentu akhir: T12.5c (ride sungguhan 30 menit).

## 1. Ringkasan
Jam Aolon GTR 3 (aplikasi GloryFit) sekarang bisa menjadi sensor detak jantung di RideComp:
1. Di Sensor, nyalakan **Tampilkan semua perangkat Bluetooth**, lalu **Periksa** jam. Jam tersimpan dengan label "Detak jantung · Jam tangan (eksperimental) · tutup GloryFit sebelum ride".
2. Saat ride, RideComp menyambung, memulai mode olahraga jam (`FD 11 02 01`), mengirim jam olahraga `FD 44` tiap detik seperti GloryFit, dan menampilkan HR di layar ride.
3. Saat ride selesai, RideComp mengirim `FD 00 02 01` (jam berhenti mengukur) lalu menutup GATT.

Karena jam hanya mengirim saat nilainya berubah, nilai terakhir ditahan dan diulang tiap detik sampai 30 dtk. Protokol ada di `04-INTEGRATIONS.md` §A.5a.

Bug lama ikut diperbaiki: sensor tersimpan dengan alamat yang bukan alamat Bluetooth (sensor simulasi debug `SIM:0x` yang terbawa ke build release) membuat `getRemoteDevice` melempar error dan mematikan **semua** sensor saat ride. Sekarang sensor seperti itu dilewati.

## 8. Penyimpangan dari spesifikasi / RULE-EXCEPTION
- Spesifikasi menyebut pesan "Putuskan dulu dari aplikasi Aolon". Catatan itu sekarang ada di subtitle sensor tersimpan ("tutup GloryFit sebelum ride"). Belum ada deteksi otomatis bahwa GloryFit sedang memegang jam.
- Perbaikan alamat sensor tidak sah (bug lama) dikerjakan di task ini, karena memblokir uji.

## 9. Risiko & bug yang diketahui
1. **Jeda HR terlama 28 dtk**, mendekati batas tahan 30 dtk. Kalau HR stabil lebih lama, kolom HR bisa kosong sebentar sampai paket berikutnya. Dipantau di T12.5c.
2. **Putus koneksi.** Di uji nRF tanpa `FD 44` koneksi putus di menit 7,5; dengan `FD 44` 10,5 mnt tanpa putus. Kalau terjadi, sambung ulang otomatis lalu START lagi (belum teramati di HP).
3. **Notifikasi `E5 11` setelah STOP** (14:01:45). Jam mungkin memulai pengukuran sendiri. GATT sudah ditutup, dan dampaknya ke baterai jam dipantau di T12.5c.
4. **Bila GloryFit terbuka,** jam tidak bisa disambung dan HR tidak muncul (tanpa crash).
5. Pembaruan firmware atau GloryFit bisa mengubah protokol (label eksperimental).

## 10. Cara menguji (untuk pemilik proyek)
1. Tutup GloryFit.
2. Sensor → **Tampilkan semua perangkat Bluetooth** → Cari → **Periksa** Aolon GTR3.
3. Ride → mulai. HR muncul ±15 dtk kemudian.
4. Selesaikan ride. Jam berhenti mengukur.
