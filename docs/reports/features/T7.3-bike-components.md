# Feature Report — T7.3: Komponen sepeda

**Tanggal:** 2026-11-17
**Branch:** `feature/T7.3-bike-components`
**Status:** Diuji di perangkat, di-merge ke `main`

## 1. Ringkasan
Tiap sepeda tersimpan bisa punya komponen (rantai, ban, kampas rem, sprocket, servis, lainnya). Jarak komponen dihitung otomatis dari ride dengan sepeda itu sejak dipasang (+ jarak awal bila bukan baru). Saat mencapai batas: bilah oranye, "Saatnya diganti atau diservis", dan "⚠ Perlu servis: Rantai" di daftar sepeda dan di persiapan ride. "Baru diganti" mengulang dari 0 km. Setiap ride kini menyimpan sepedanya.
