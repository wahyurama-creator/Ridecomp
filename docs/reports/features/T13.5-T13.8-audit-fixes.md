## 8. Penyimpangan dari spesifikasi / RULE-EXCEPTION

## 9. Risiko & bug yang diketahui
1. Belum diaudit di 320 dp: Detail rute, editor komponen sepeda, layar insiden, bantuan Strava, galeri share, editor segmen.
2. Utang UI-07 lama (sama di semua lebar): swatch share 32 dp, tab 48 dp, chip Profil aktivitas, baris Bahasa, kotak halaman data 47 dp (audit §3a).

## 10. Cara menguji (untuk pemilik proyek)
`adb shell wm size 720x1280 && adb shell wm density 360`, buka onboarding (HP baru) → tombol Mulai terlihat; kembalikan dengan `wm size reset` dan `wm density reset`.
