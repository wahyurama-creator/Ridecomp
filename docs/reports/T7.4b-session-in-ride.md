# Feature Report — T7.4b: Sesi rencana di ride

**Tanggal:** 2026-11-17
**Branch:** `feature/T7.4b-session-in-ride`
**Status:** Menunggu uji perangkat jalur detak jantung (lihat §6)

## 1. Ringkasan
- **Beranda:** kartu "RENCANA · BASE ZONA 2 · MINGGU 1/4 — Hari ini: Zona 2 · Daya tahan · 45 mnt" + cara merasakannya + tombol **MULAI SESI**; hari istirahat: "Hari ini istirahat".
- **Persiapan ride:** "Sesi hari ini: …" dengan sakelar (aktif default) — dimatikan bila ingin ride bebas.
- **Layar ride:** bilah target di atas halaman data: "Z2 · 128 bpm · di zona · Target 114–133 bpm · 12:30 / 45:00"; sumber HR (HR max profil atau 220 − umur) → power (FTP) → rasa tanpa sensor. Warna: hijau di zona, oranye terlalu berat.
- **Alert:** sesi Zona 1–2 yang terlalu berat ≥ 20 dtk → getar ganda + suara "Terlalu berat untuk zona 2. Pelankan sedikit." (paling sering sekali per menit); semua sesi: "Sesi selesai. Mantap!" sekali saat waktu bergerak mencapai durasi. Sesi Z3–Z5 tidak memberi alert "di bawah zona" agar istirahat antar-interval tidak memicu alarm.
- Sesi disimpan bersama ride (`training.ride_target`) sehingga ride yang dipulihkan tetap diukur.
