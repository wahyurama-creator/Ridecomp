# Feature Report — T7.2: Kembali ke start

**Tanggal:** 2026-11-17
**Branch:** `feature/T7.2-back-to-start`
**Status:** Diuji di perangkat, di-merge ke `main`

## 1. Ringkasan
Tombol **Ke start** di halaman Peta: jalur yang sudah dilalui menjadi jalan pulang (oranye) dengan titik start hijau; bilah bawah menunjukkan jarak lewat jalur tadi, panah arah ke start, dan jarak garis lurus; dekat start muncul "✓ Sudah sampai di start". Bekerja dengan peta online, file offline, atau garis saja (tanpa internet).

## 2. Perubahan per lapisan
| Lapisan | File/kelas | Keterangan |
|---|---|---|
| Domain (`:core`) | `engine/map/BackToStart.kt`, `GeoMath.bearingDeg` | Jarak lewat jejak, garis lurus, arah, sampai (≤ 30 m) |
| UI (`:ui-common`) | `RouteMap(marker)`, `ic_flag`, `ic_navigation` | Titik penanda hijau; ikon |
| Presentation (`:feature-ride`) | `RideViewModel` (`backToStart`, `toggleBackToStart`, jejak dibagi `shareIn`), `RideScreen` (`BackToStartButton`, `BackToStartBar`), `RideMapView` | Jejak kini di semua ride ber-GPS |

## 9. Risiko & bug yang diketahui
- Tanpa belokan per belokan: pengguna menyusuri garis di peta (bukan navigasi suara).
- Jejak yang dipadatkan (> 2.000 titik) sedikit memendekkan jarak "lewat jalur tadi" pada ride sangat panjang.

## 10. Cara menguji
Mulai ride, bergerak sebentar, geser ke halaman Peta, ketuk **Ke start**; ketuk **Tutup** untuk kembali.
