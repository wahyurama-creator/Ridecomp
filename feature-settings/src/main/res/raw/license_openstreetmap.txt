RideComp displays map region files (PMTiles, Protomaps basemap schema): files you import yourself and the province map packs published with RideComp (cut from the Protomaps daily build, https://protomaps.com). The map data inside those files comes from OpenStreetMap; attribution: © OpenStreetMap contributors, Protomaps.

The online map uses OpenFreeMap tiles (https://openfreemap.org, OpenMapTiles schema), also OpenStreetMap data: © OpenFreeMap © OpenMapTiles © OpenStreetMap contributors.
